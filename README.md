# WatchService

ASP.NET Core Web API project for managing watch sales.

## Architecture
- N-tier architecture (Host, BL, DL, Models, Tests)
- MongoDB Atlas
- Dependency Injection
- Serilog
- Swagger
- FluentValidation
- HealthChecks
- xUnit + Moq unit tests

## Features
- CRUD operations for watches
- Sell watch business logic
